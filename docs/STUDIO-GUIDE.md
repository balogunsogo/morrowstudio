# Editing the Morrow Studio website

## Log in

Open [Morrow Studio](https://morrow-studio.sanity.studio) and sign in with the Sanity account invited to this project. Use your own account. If you cannot see the content, ask the website team to check your access.

The **Content** tool contains Home, About and Projects. **Presentation** lets you preview the website while editing. You can leave Vision to the website team.

## Home

- **Hero:** the studio name, opening copy, image, location and availability.
- **Featured Work:** choose up to six projects; drag to change their order. Preview image-size choices before publishing.
- **Studio:** statement, supporting copy and services.
- **Project Index:** the projects listed lower down on Home and the opening copy on Work.
- **Footer:** contact copy, email addresses, social links and location details.
- **Mobile:** optional shorter introduction and project index for small screens.

## About

Use Intro, Images and Biography for the studio story. Capabilities contains a title and description for each service. Clients and Recognition have ordered lists. Contact contains email, address and social details. Mobile contains optional shorter versions.

Keep any bracketed wording, such as `[Founder name]` or `[Studio address]`, until you have a confirmed replacement. The warning is a reminder; it does not prevent unrelated edits from being published.

## Projects

Open a project in Content → Projects.

- **Overview:** title, year, client, sector, location, summary and Project order.
- **Archive:** the cover image and Archive filters used on the Work page.
- **Case Study:** the main hero image, services and story sections. Open a section to edit it; drag sections to change their order.
- **Mobile:** optional hero, shorter labels and section selection for small screens.

**Project order** controls the Work archive and the next-project sequence. Use a different number for every project. Home’s featured projects and project index have their own ordered selections.

## Text and images

Click into text to edit it. Use the text toolbar for headings, emphasis and links. Keep headings short and check longer copy in Presentation.

For an image, choose or upload the replacement, then check its crop and hotspot. Write alternative text describing what the image shows for people using screen readers. Captions are visible on the website; alternative text serves a different purpose.

A gallery needs at least two images. Credit rows contain a collaborator’s role and name. Their previews help you find the right entry without opening every item.

## Desktop and mobile

The main content is used on both screen sizes unless you choose otherwise.

Leave optional **Mobile version** fields empty to use the main content. Fill in only the image, caption or copy that needs to differ. **Device visibility** controls whether an entire section or gallery image appears on both devices, desktop only or mobile only.

Mobile selection controls show readable names. Choose an item to add it, drag to reorder, or use the row menu to remove it. **Use default order** returns to the main content order. An explicit empty selection shows no items. Removing an item from a mobile selection does not delete its main content.

If an item is marked Unknown, choose a replacement or remove that selection only when you know what should appear. Ask the website team if you are unsure.

## Preview, drafts and publishing

Changes save automatically as drafts. Visitors continue seeing the published version until you choose **Publish**.

1. Open Presentation and find the page you are editing.
2. Check both desktop and mobile views. You can click highlighted content in the preview to find its field.
3. Review warnings and resolve any validation errors.
4. Choose Publish when the page is ready, then check the public page.

Presentation opens [the Morrow Studio website](https://morrowstudio.balogunoluwasogo.com). If it does not load, ask the website team to check the website address and preview connection; you can keep editing drafts.

## Films with a poster only

Some films are intentionally waiting for a video source. Their poster and caption display on the website without playback. This warning does not block other edits.

When the source is confirmed, choose **Uploaded video** or **Website link**, then add the corresponding source. Keep only one source: clear an old file before using a link, or clear an old link before using a file. Preview before publishing.

## Accidental edits and fields to leave alone

Use Undo immediately after a mistake. For an unwanted draft, open the document’s action menu and discard its unpublished changes; this removes all draft edits for that document, including any made by collaborators, so check with them first.

If an unwanted edit was already published, open the document history, find the earlier version and restore it. Preview the restored draft, then publish when confirmed. Ask the website team for help if you are uncertain.

Leave existing page addresses, read-only original content, device visibility and film source settings alone unless you have a specific reason to change them. You do not need to edit identifiers or use Vision during normal website editing.
