# Morrow Studio: Awwwards Readiness Audit

Audit date: 8 October 2026. Initial repository: clean worktree. This is a fictional, self-initiated studio concept. Fictional projects and editorial identity are intentional.

## Executive Summary

The source audit and initial browser baseline are complete. Safe fixes address failing quality checks, CMS fallbacks, keyboard bypass, responsive labels, recovery, editorial validation, project pre-rendering and a desktop gallery snapping race. Phase 2 applies the approved Home label contrast correction, ordered mobile Home selection and request-time sitemap freshness. The public site's existing canonical/indexing configuration is preserved. Deployed Lighthouse measurements expose remaining mobile performance work; these measure the existing live build, not the undeployed Phase 2 fixes. Final sign-off still requires creator decisions and physical-device/assistive-technology review. This is a focused readiness pass, not a redesign or an award guarantee.

## Current Architecture

- Next.js 16.3.8 App Router, React 19.2.8, TypeScript, SCSS modules/shared Sass, Tailwind 4 base utilities.
- Server components fetch Home, About, Work and projects through next-sanity 13.3.4 `defineLive`/`sanityFetch`. Published reads are cached by Next; authenticated draft reads use a server-only Viewer token. Browser tokens are disabled.
- Sanity 5.31.2: Home/About singletons, project documents, ten case-study block types, custom keyed mobile-order inputs, Structure, Vision and Presentation. Embedded `/studio/[[...tool]]`; standalone Studio uses the existing CLI scripts. Website deployment configuration is not versioned here; no deployment is authorized in this task.
- Public routes: `/`, `/work`, `/about`, ten published `/work/[slug]` case studies; metadata routes `/robots.txt`, `/sitemap.xml`; three draft-mode API routes. Published slugs were confirmed by read-only CMS inventory.
- Main component groups: HomeHero/FeaturedProjects/StudioStatement/ProjectHoverIndex; WorkIndex/WorkRow/WorkCard; AboutHero/AboutImages/AboutBio/Capabilities/Clients/Recognition; ProjectHero/ProjectMetadata/ProjectContent/NextProject and ten block renderers; shared navigation/native modal menu/footer/image/text reveals/smooth wheel handler; preview-only tools and refresh polling.
- Content: almost all editorial text, images, ordering, disciplines, social destinations and footer details come from Sanity. Navigation labels/contact mailto, section labels, gallery controls, copyright and fallback messages are hardcoded. About contact fields exist but the About route currently uses the shared Home footer.
- Assets: Sanity CDN images through server-side `getImageProps` and Next optimization; responsive `sizes`, source crop/hotspot and CSS composition rules. `public/` contains five starter SVGs (3,314 bytes), unused by the rendered portfolio. Reference imagery and migration fixtures live in the source export/migration directories. Geist/Geist Mono are fetched at build time by next/font and served locally at runtime.
- Motion: no GSAP dependency or ScrollTrigger. CSS title/word/image reveals, CSS gallery translation, IntersectionObserver/ResizeObserver, native modal, and a requestAnimationFrame wheel glide for non-pixel wheel events. Pixel wheel/touch remain native; reduced motion is supported in CSS and JS.
- Breakpoints: mobile <=760px; desktop >=761px; tablet overrides <=1024px. Case-study content has separate SSR branches, mobile images/order/visibility. Home uses mobile copy/index selections; Work uses mobile thumbnails/scrolling filters instead of hover preview. Galleries use desktop translation and mobile native snapping. Hover effects require fine pointers.
- Dependencies: Portable Text, Sanity client/image builder/icons/UI/Vision/next-sanity/Sanity, React, styled-components; development tools TypeScript, ESLint, Sass, Tailwind/PostCSS, tsx, jsdom, Playwright. Studio accounts for much of the dependency tree; its costs must not be confused with public-route transfer.
- Tests: Node contracts/migration/keyed-input/editor UX; Playwright contract/completion/preview/studio-key/scroller/interaction/visual drivers. Existing docs: README, STUDIO-GUIDE, STUDIO-DEPLOYMENT, SANITY_PREVIEW and migration completion/refinement reports. Existing historical passes are not evidence for this audit's results.

## Verification Method

Verification used existing Node/Playwright tools, installed axe-core, lint, TypeScript, website/Studio builds, read-only CMS/hosting inventory and fresh-context browser timing. All public pages were tested at the nine requested widths plus 760/761px. Baseline/post-change JSON and screenshots are retained in ignored `.tmp/awwwards/`.
