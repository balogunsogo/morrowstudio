Forma

A practice website that reads like a monograph.

Year
2025
Services
Website
Digital design
Development
Client
Forma Architects

(Overview)

A fourteen-person architecture practice whose portfolio lived in a 60-page PDF. We replaced it with a website the practice keeps current itself.

Clients writing shortlists, planning officers and job applicants all need to find comparable buildings quickly, so the site is organised around projects, not the practice.

Fig. 02–03 — Hollis Road School; courtyard

Drawings deserve the same space as photographs.

(Drawings)

Plans you can read at any size.

Drawings upload as vector files, so they stay sharp when pinched to zoom on a phone. Scale and floor sit in the caption, never inside the image.

(Structure)

Each project is entered once with sector, location, stage, size and status, so the index filters by any of them. A council looking for completed schools finds them in two taps.

Outcome: [X]% of new-business enquiries now arrive through the site.

“We used to email a PDF and hope. Now we send a link to the three projects that matter for that client.”

— Founding partner, Forma Architects
